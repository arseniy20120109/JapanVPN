## О проекте

Alpha VPN — это VPN-клиент, созданный с упором на простоту, скорость и приватность.  
Версия **1.0** — первый стабильный релиз.

## Release notes

> This is the first release of the VPN. There are no known bugs so far, but if you find any, please let us know.

Перевод: это первый релиз VPN. На данный момент известных багов нет, но если вы найдёте проблему — пожалуйста, сообщите нам.

## Возможности

- Быстрое подключение к серверам в один клик
- Шифрование трафика
- Простой и понятный интерфейс
- Поддержка нескольких платформ
- Нет известных багов в релизе 1.0

## Поддерживаемые платформы

- Android
- Windows
- macOS
- Linux

## Установка

```bash
# склонируйте репозиторий
git clone https://github.com/USER/REPO.git

# перейдите в папку проекта
cd REPO
```

Дальше следуйте инструкции для вашей платформы (добавьте сюда шаги сборки/установки).

## Использование

1. Запустите Alpha VPN.
2. Выберите сервер.
3. Нажмите «Подключиться».

## Как добавлять картинки, гифки и другое в README

Всё ниже — примеры синтаксиса Markdown для GitHub. Просто замените ссылки на свои файлы.

### 1. Обычная картинка

```markdown
![Описание](https://example.com/image.png)
```

Или со своего репозитория (положите файл в папку `images/` и закоммитьте):

```markdown
![Alpha VPN](images/logo.png)
```

### 2. Картинка по ссылке из интернета

```markdown
![Логотип](https://raw.githubusercontent.com/USER/REPO/main/images/logo.png)
```

### 3. GIF-анимация

Гифка вставляется точно так же, как картинка — GitHub сам её проиграет:

```markdown
![Демонстрация](images/demo.gif)
```

>Совет: гифки весят много. Если гифка больше ~10 МБ, лучше загрузить её на imgur/giphy и вставить внешней ссылкой.

### 4. Видео

GitHub поддерживает встроенное видео через `<video>`:

```html
<video src="https://example.com/demo.mp4" controls width="600"></video>
```

Или просто ссылкой на YouTube:

```markdown
[▶ Смотреть демо на YouTube](https://www.youtube.com/watch?v=VIDEO_ID)
```

### 5. Бейджи (шильдики)

Сервис [shields.io](https://shields.io) генерирует бейджи:

```markdown
![Build](https://img.shields.io/badge/build-passing-brightgreen)
![Downloads](https://img.shields.io/badge/downloads-1k-blue)
```

### 6. Картинка-кнопка (кликабельная)

```markdown
[![Скачать](https://img.shields.io/badge/Download-APK-green)](https://github.com/USER/REPO/releases)
```

### 7. Выравнивание по центру (через HTML)

```html
<p align="center">
  <img src="images/logo.png" width="400">
</p>
```

### 8. Несколько картинок в ряд

```html
<p align="center">
  <img src="images/screen1.png" width="30%">
  <img src="images/screen2.png" width="30%">
  <img src="images/screen3.png" width="30%">
</p>
```

### 9. Добавление файлов в репозиторий

```bash
mkdir -p images
# положите ваши .png / .gif / .jpg в папку images/
git add images/
git commit -m "Add screenshots and demo gif"
git push
```

После этого используйте пути вида `images/имя_файла.png` в README.
